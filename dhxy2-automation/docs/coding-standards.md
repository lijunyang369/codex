# 《大话西游2》项目代码补充规范

## 1. 文档定位

本文档不是项目的独立全局代码规范。

本项目默认继承工作区通用规范：

- `D:\Codex\standards\global-coding-standards.md`

本文档只补充《大话西游2》战斗自动化项目特有的实现约束。

## 2. 项目补充约束

### 2.1 分层约束

- `policy` 不直接调用 Airtest 和 win32 API
- `executor` 不决定业务策略
- `state_machine` 不关心具体点击细节
- `perception` 不直接修改运行状态

### 2.2 识别约束

- 所有识别结果必须带置信度
- 不允许只返回布尔值作为最终识别结果
- OCR、模板匹配、区域识别都必须可留证

### 2.3 自动化约束

- 业务层禁止直接写绝对屏幕坐标
- 所有动作必须经由统一执行层发出
- 关键动作前后必须保留日志或截图证据

### 2.4 稳定性约束

- 异常不得静默吞掉
- 恢复流程必须可追踪
- 关键状态迁移必须记录日志
- 高风险动作必须可回放上下文

## 3. 结论

本项目代码实现先遵守全局代码规范，再遵守本补充规范。

若两者冲突，以更严格者为准。
