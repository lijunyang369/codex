# 项目说明

`ocr-service` 是工作区级 OCR 服务，只负责 OCR 能力本身，不承载业务策略。

边界：
- 负责 provider 装配、图片读取、预处理和统一输出
- 不负责业务状态机、规则判断、按钮策略和页面流程
- 其它项目通过 HTTP 调用，不直接依赖 OCR provider 运行时

稳定性原则：
- 输入边界必须清晰，非法图片和越权路径要快速失败
- provider 故障要返回明确的降级状态或错误
- 接口输出格式保持稳定，便于上游项目长期集成

设计原则：
- 先保证运行时隔离，再考虑识别能力扩展
- 先保证接口稳定，再增加 provider 特性
- 先保证本机复用，再考虑更复杂的部署形态
