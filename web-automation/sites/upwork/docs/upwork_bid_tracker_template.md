# Upwork 投标记录表模板

日期: 2026-03-24

用途:

- 记录每次投标
- 比较不同岗位方向的回复率
- 找出更适合自己的 proposal 和 client 类型

建议:

- 每投一单就补一条
- 每投满 5 到 10 单做一次复盘

## 字段说明

### 基础信息

- 投标日期
- 职位标题
- 职位链接
- 岗位类型
- 技术关键词
- 预算类型
- 预算金额
- Connects 消耗

### Client 信息

- 国家/地区
- Payment verified
- 历史评价
- 已花费金额
- 最近活跃
- 是否新 client

### 匹配判断

- 匹配方向
- 为什么投
- 风险点
- 本单目标

### Proposal 信息

- proposal 版本
- 是否强调 `Phase 1 / MVP`
- 是否限制了范围
- 是否带 Portfolio

### 结果跟踪

- 是否已提交
- 是否被查看
- 是否回复
- 是否进入 interview
- 是否进入试合作
- 是否成交
- 最终结果

### 复盘

- 这单值不值得投
- proposal 哪部分有效
- 下次要不要继续投同类
